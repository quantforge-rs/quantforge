Run the polling strategy bot against SQLite-backed live candles

Usage: quantforge trade run [OPTIONS] --symbol <SYMBOL>

Options:
      --db <DB>
          SQLite database path [env: QF_DB=] [default: data/market.sqlite]
      --symbol <SYMBOL>
          
      --exchange <EXCHANGE>
          Exchange to connect to [env: QF_EXCHANGE=] [default: binance] [possible values: binance]
      --interval <INTERVAL>
          [default: 1m]
      --base-url <BASE_URL>
          Exchange API base URL; omitted, the exchange's production endpoint [env: QF_BASE_URL=]
      --fast <FAST>
          [default: 20]
      --log-level <LOG_LEVEL>
          Log filter (trace, debug, info, warn, error or a full tracing filter expression) [env: QF_LOG=] [default: info]
      --slow <SLOW>
          [default: 50]
      --quote-order-qty <QUOTE_ORDER_QTY>
          [default: 100]
      --mode <MODE>
          [default: dry-run] [possible values: dry-run, live]
      --yes
          
      --poll-secs <POLL_SECS>
          [default: 5]
      --bootstrap-bars <BOOTSTRAP_BARS>
          [default: 300]
      --bootstrap-enter
          
      --limit <LIMIT>
          [default: 1000]
      --run-id <RUN_ID>
          
      --max-loops <MAX_LOOPS>
          
  -h, --help
          Print help

Exchange credentials:
      --api-key <API_KEY>        API key for the exchange's signed endpoints (monitor, trade close, trade run --mode live); prefer QF_API_KEY: command-line values can land in shell history and process listings [env: QF_API_KEY]
      --api-secret <API_SECRET>  API secret paired with --api-key; prefer QF_API_SECRET: command-line values can land in shell history and process listings [env: QF_API_SECRET]
