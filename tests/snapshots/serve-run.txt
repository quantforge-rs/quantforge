Answer HTTP requests until Ctrl-C or SIGTERM, then finish the ones in progress

Usage: quantforge serve run [OPTIONS]

Options:
      --listen <LISTEN>                IP address and port to listen on; port 0 picks a free port [env: QF_LISTEN=] [default: 127.0.0.1:9600]
      --max-span-bars <MAX_SPAN_BARS>  Most bars one /v1/candles answer or backtest job may span; a longer range is refused [env: QF_MAX_SPAN_BARS=] [default: 527040]
      --job-concurrency <COUNT>        Backtest jobs that run at once, the rest waiting their turn; omitted, half the CPU cores [env: QF_JOB_CONCURRENCY=]
      --exchange <EXCHANGE>            Exchange to connect to [env: QF_EXCHANGE=] [default: binance] [possible values: binance]
      --base-url <BASE_URL>            Exchange API base URL; omitted, the exchange's production endpoint [env: QF_BASE_URL=]
      --log-level <LOG_LEVEL>          Log filter (trace, debug, info, warn, error or a full tracing filter expression) [env: QF_LOG=] [default: info]
  -h, --help                           Print help

Job limits:
      --job-cpu-secs <SECS>   CPU time one backtest job may use, in seconds; a job that uses more is stopped [env: QF_JOB_CPU_SECS=] [default: 600]
      --job-memory-mib <MIB>  Memory one backtest job may use, in MiB of address space; enforced on Linux [env: QF_JOB_MEMORY_MIB=] [default: 4096]
      --job-wall-secs <SECS>  Wall-clock time one backtest job may run, in seconds, before it is stopped [env: QF_JOB_WALL_SECS=] [default: 1800]

Storage:
      --db <DB>
          SQLite database path; refused with --storage postgres [env: QF_DB=] [default: data/market.sqlite]
      --storage <STORAGE>
          Storage backend [env: QF_STORAGE=] [default: sqlite] [possible values: sqlite, postgres]
      --postgres-url <POSTGRES_URL>
          PostgreSQL URL, postgres://USER:PASSWORD@HOST:PORT/DATABASE, optionally with sslmode and sslrootcert; prefer QF_POSTGRES_URL: command-line values can land in shell history and process listings [env: QF_POSTGRES_URL]
      --postgres-pool-size <POSTGRES_POOL_SIZE>
          Most PostgreSQL connections this process opens; omitted, 2, or 8 for serve run [env: QF_POSTGRES_POOL_SIZE=]
      --postgres-connect-timeout-secs <POSTGRES_CONNECT_TIMEOUT_SECS>
          Seconds opening a PostgreSQL connection, TLS included, may take [env: QF_POSTGRES_CONNECT_TIMEOUT_SECS=] [default: 5]

Exchange credentials:
      --api-key <API_KEY>        API key for the exchange's signed endpoints (monitor, trade close, trade run --mode live); prefer QF_API_KEY: command-line values can land in shell history and process listings [env: QF_API_KEY]
      --api-secret <API_SECRET>  API secret paired with --api-key; prefer QF_API_SECRET: command-line values can land in shell history and process listings [env: QF_API_SECRET]
